**Status**: Draft

## 1. Core Entities

### 1.1 DungeonPropAsset
Represents an individual interactive or scenery prop archive located in `obj/o*.objbnd.dcx` or environment map pieces.

| Field | Type | Description |
| :--- | :--- | :--- |
| `asset_id` | `str` | Model identifier (e.g. `o290250`, `o290000`, `o297210`, `o322050`). |
| `category` | `enum` | One of `CAGE`, `CADAVER_WASTE`, `MECHANISM`, `FURNITURE`, `CONTAINER`. |
| `flver_count` | `int` | Number of `.flver` models contained in the binder. |
| `has_anibnd` | `bool` | True if binder contains `.anibnd` dynamic animation tracks. |
| `has_hkx` | `bool` | True if binder contains `.hkx` Havok collision data. |
| `is_multi_bone` | `bool` | True if FLVER contains > 1 bone in skeleton hierarchy. |
| `meshes` | `List[SubmeshRecord]` | Array of submeshes with materials, face sets, and vertex buffers. |
| `dummies` | `List[DummyAnchor]` | Interaction and visual effect anchor points. |

#### Validation Rules:
- If `has_hkx == True`, collision data MUST NOT be modified or stripped.
- If `has_anibnd == True`, animation track bindings and bone hierarchy MUST remain intact.
- `dummies` count and coordinates MUST be bit-for-bit preserved relative to model root.

### 1.2 CageAssembly
Specialized subclass or configuration of `DungeonPropAsset` representing hanging cages, elevator cages, and deformed torture cages.

| Field | Type | Description |
| :--- | :--- | :--- |
| `cage_type` | `enum` | `CYLINDRICAL_HANGING`, `ELEVATOR_PULLEY`, `DEFORMED_TORTURE`, `DOG_PRISON`. |
| `target_tris` | `int` | Target decimation triangle count (budget: 200–800 triangles). |
| `orig_tris` | `int` | Vanilla triangle count prior to demake. |
| `reduction_ratio` | `float` | Triangle decimation ratio ($1.0 - \text{target}/\text{orig} \ge 0.70$). |
| `shading_mode` | `enum` | Flat facet normals (`SHADE_FLAT`). Smooth shading prohibited. |
| `color_format` | `enum` | 15-bit RGB555 palette quantization. |

#### Validation Rules:
- Cage bars MUST exhibit flat facet normals (`norm_diff > 0.0` across adjacent coplanar faces).
- Reduction ratio MUST achieve $\ge 70\%$ triangle reduction without creating open boundary cracks in primary bar rings.

### 1.3 CadaverWasteMesh
Specialized prop mesh representing mass corpse piles, dead hunters, and hanging cadavers.

| Field | Type | Description |
| :--- | :--- | :--- |
| `mesh_index` | `int` | Index of submesh within the FLVER container. |
| `default_bone` | `int` | Bone index to which this submesh is anchored. |
| `local_bounds` | `AABB` | Extrema $[\mathbf{P}_{\min}, \mathbf{P}_{\max}]$ in bone-local coordinate space. |
| `world_bounds` | `AABB` | Extrema accumulated through bone transform hierarchy. |
| `max_edge_len` | `float` | Maximum length of any triangle edge in meters (limit $\le 2.0$m). |
| `max_aspect` | `float` | Triangle aspect ratio $\rho = \frac{abc}{8(s-a)(s-b)(s-c)}$ (limit $\le 25.0$). |
| `min_face_area` | `float` | Triangle surface area in m$^2$ (limit $\ge 10^{-6}$ m$^2$). |

#### Validation Rules:
- `max_edge_len` MUST NOT exceed 2.0 meters (prevents exploded vertex sheets).
- Zero triangles with area $< 10^{-6}$ m$^2$ (degenerate slivers culled).
- `world_bounds.min.y` MUST be clamped to ground plane ($\Delta Y \ge -0.05$m).

### 1.4 ModularModPillar
Represents one of the five independent mod deliverables under `mods/`.

| Field | Type | Description |
| :--- | :--- | :--- |
| `pillar_id` | `enum` | `MAPS`, `PROPS_OBJECTS`, `ARMORS_WEAPONS`, `CHARACTERS`, `HUD_UI`. |
| `mod_name` | `str` | Display name (e.g. `Bloodborne Retro Props and Objects`). |
| `install_path` | `Path` | Destination directory (e.g. `mods/Bloodborne Retro Props and Objects/`). |
| `dvdroot_subpath` | `str` | Target subfolder (`map`, `obj`, `parts`, `chr`, `menu`). |
| `file_count` | `int` | Number of modified delta assets included. |
| `total_size_mb` | `float` | Total uncompressed payload size in MiB. |
| `is_standalone` | `bool` | True if pillar can load into `bbport` without requiring other pillars. |

#### Allowed Subpath Matrix:

| Pillar | Subpath | Allowed Asset Extensions |
| :--- | :--- | :--- |
| `MAPS` | `dvdroot_ps4/map/` | `*.flver.dcx`, `*.tpfbdt`, `*.tpfbhd`, `*.msb.dcx` |
| `PROPS_OBJECTS` | `dvdroot_ps4/obj/` | `*.objbnd.dcx` |
| `ARMORS_WEAPONS` | `dvdroot_ps4/parts/` | `*.partsbnd.dcx` |
| `CHARACTERS` | `dvdroot_ps4/chr/` | `*.chrbnd.dcx`, `*.tpf.dcx` |
| `HUD_UI` | `dvdroot_ps4/menu/` | `*.tpf.dcx` |

### 1.5 MultiModelAuditReport
Structured quality audit record generated by an alternate model (Sonnet 4.6 in AGY).

| Field | Type | Description |
| :--- | :--- | :--- |
| `audit_id` | `str` | Unique timestamped audit ID (e.g. `AUDIT-20261108-PROPS`). |
| `auditor_model` | `str` | Alternate model identifier (e.g. `claude-3-7-sonnet` / Sonnet 4.6). |
| `target_pillar` | `str` | Modular pillar audited. |
| `checks_evaluated` | `int` | Total number of automated and visual checks executed. |
| `violations_found` | `int` | Number of detected anomalies (MUST be 0 for release sign-off). |
| `overall_verdict` | `enum` | `PASS` or `FAIL`. |
| `findings` | `List[AuditFinding]` | Granular details of any detected discrepancy or confirmation note. |
